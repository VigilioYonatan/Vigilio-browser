# Identidad visual del instalador de Vigilio Browser

**Referencia aprobada por el usuario:** `branding/vigilio-installer-brand-reference.png`.

Se utiliza el globo celeste/azul con órbita y pequeña estrella, en un cuadrado oscuro de esquinas redondeadas; a su derecha, la marca blanca «Vigilio Browser». La versión recortada `vigilio-installer-icon-reference.png` es una referencia raster de trabajo; **no sustituye un icono vectorial final** ni está validada a tamaños pequeños. El gráfico completo proviene de la imagen entregada por el usuario.

## Reglas para el instalador

- El instalador debe utilizar la marca oficial sin inventar un logotipo alternativo.
- Mantener jerarquía tipográfica y espaciados de un instalador nativo, sin neón decorativo invasivo.
- La experiencia que antes se identificaba internamente como Modo Senior se presenta al público como **«Interfaz más fácil de usar»**.
- No mostrar términos internos como «prompt», «skill», «OpenSpec», «micro-pack», «PROPOSE», «APPLY» o «Senior Mode» en la UI pública.
- Mostrar opciones comprensibles: ubicación, acceso directo, importar favoritos, tema y accesibilidad.
- El icono de aplicación para Windows/macOS/Linux debe exportarse desde un archivo maestro reproducible y probarse visualmente. Esta versión añade referencias gráficas, no instaladores compilados.
