# Plan de cambio y reversión

1. Proyecto de código creado en carpeta separada `Vigilio_Browser_Starter`. Super Skills v1.0, v1.1, v1.2 y skill Senior v3.0 **sin modificar**.
2. Si no deseas seguir usando este starter: elimina la carpeta creada; no contiene datos ni perfiles personales de usuario.
3. No publicar como versión estable ni utilizar para navegar con datos sensibles sin revisión y recompilación de Qt en un entorno actualizado.
4. En un futuro, el upgrade de DB debe incluir migración versionada y respaldo reversible; esta alpha crea dos tablas en una DB local sin migraciones automáticas complejas.
