# Brief — Vigilio Browser
**Problema**: navegadores útiles pero pesados, con interfaces saturadas o dependencia de cuentas. **Objetivo**: producto profesional y accesible, privado y optimizado, con todas las herramientas bajo demanda. **Público**: usuarios generales, seniors (Modo Senior es configuración accesible, no perfil de edad), desarrolladores, usuarios avanzados. **Plataformas**: Win10/11 x64, Linux x64, macOS Intel y Apple Silicon (target sujeto a evidencia). **No objetivos**: nube/login/sync Vigilio, telemetría obligatoria, herramienta pesada residente, equivalencia total Chrome Web Store, integración IA obligatoria. **Alcance**: catálogo en docs/rules/05-reference/feature-inventory.md.

**Flujos críticos**: navegar/restaurar tabs; descargas y permisos; Shields por sitio; exportar/importar y conservar datos al desinstalar; acceder desde teclado a cualquier control; ejecutar MCP autorizado y revocarlo; instalar/actualizar/desinstalar sin perder perfiles. **Riesgos**: cadena Chromium Qt, seguridad del sandbox, cambios API Qt extensiones, rendimiento total multiproceso, distribución. **NFR**: accesibilidad WCAG2.2 AA donde aplique; no UI blocking IO; modo reducido de animación; privacidad local. **Criterios de éxito**: métricas reproducibles, escenarios críticos aprobados y cumplimiento del definition of done.
