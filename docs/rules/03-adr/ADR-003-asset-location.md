# ADR-003 — Assets embebidos dentro de apps/vigilio-browser/assets
**Estado**: Approved concept (no runtime verified). **Contexto**: Vigilio Browser local-first en Windows/Linux/macOS, memoria como restricción y privacidad prioritaria. **Decisión**: Assets embebidos dentro de apps/vigilio-browser/assets. **Drivers**: mantenimiento, privacidad, UX accesible, recursos limitados. **Alternativas**: cloud/login, tecnología ajena a C++ Qt, assets en raíz, E2E masivos paralelos y UI ornamental; rechazadas por decisiones explícitas del usuario. **Consecuencias**: menos dependencias externas y más trabajo en pruebas nativas. **Impacto security/data**: no nuevos servicios remotos; operaciones locales auditables. **Migración**: actualizar owners/contratos y no copiar código sin evidencia. **Rollback**: requiere nueva decisión humana, no se cambia silenciosamente. **Evidencia**: conversation decisions captured in answers.md; runtime NOT_EXECUTED.
