# Catálogo de pantallas y contratos
| Pantalla | Acceso | Presentación senior | Acción/estados/teclado |
|---|---|---|---|
| Navegador | lanzamiento | tabs claras, dirección central, sidebar opcional | loading/error/retry; Alt+Left, Ctrl+L, Ctrl+T |
| Nueva pestaña | Ctrl+T | wallpaper opcional solo aquí, search central, accesos | empty/normal; Ctrl+L |
| Menú pestaña | clic derecho | íconos 16-20px + texto, grupos y separadores | cerrar otras/derecha, pin, mute, split, restore; Escape |
| Ajustes | menú → Ajustes | navegación categorías, títulos 18px | guardado local/error; Tab/Shift+Tab |
| Senior Mode | onboarding, ajustes, Ctrl+K | targets 44–48px, contrast, labels, motion reduced | activar, previsualizar, revertir |
| Shields panel | escudo barra URL | on/off por sitio + contadores claros | active/disabled/error; Enter/Escape |
| Perfil local | selector perfil | cuenta local de navegación, no login Vigilio | isolate/logout site not profile |
| Workspaces | barra lateral | lista espacios renombrable | create/rename/remove, restore |
| Split view | menu pestaña | paneles redimensionables | 2–4 hasta ancho útil, keyboard focus |
| Historial | menú/barra lateral | búsqueda y agrupación | resultados, borrar rango, restore |
| Favoritos | estrella/lista | etiquetas completas, carpetas | save/remove/search/import |
| Descargas | flecha/barra lateral | progreso y destino | running/completed/paused/error |
| Herramientas | sidebar | íconos consistente y descripción | visores, QR, capturas, notas, lector |
| Visores | open file/menu | árbol/tablas virtuales, zoom | loading/invalid/huge/security error |
| Extensiones | puzzle/Ajustes | lista with permissions | MV3 Qt-compatible only, explicit install |
| MCP/agentes | ajustes avanzada | permisos y detener agente | deny by default, audit local, revoke |
| Diagnostics | herramientas avanzada | métricas bajo demanda | sampling stop when closed |
| Backup | ajustes → datos | pasos claros y preview | export/import/restore/cancel/error |
| Instalador | ejecutable plataforma | 5 pasos legibles con foco | bienvenida/ruta/componentes/import/progreso/fin |
| Desinstalador | sistema operativo | default conservar perfil; export optional | clear warning, cannot accidentally delete profile |
