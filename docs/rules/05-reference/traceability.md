# Trazabilidad
Cada pack `module.*` enlaza a su owner `01-modules/<slug>`, step, tests, execution-memory y openspec change. El plan enumera IDs que deben existir en registry. Al marcar tarea completada, vincular commit SHA, comando, exit status, OS/Qt version y evidencia; sin ello queda TARGET/NOT_EXECUTED. `answers.md` tiene prioridad para decisiones humanas.
