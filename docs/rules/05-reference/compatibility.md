# Prompt Builder / OpenSpec compatibilidad
Toolchain source: `prompt-buildewr(3).zip`, package `@vigilio-services/prompt-builder` v0.6.3, engines Node >=24 <25, pack schema_version 2, plan schema_version 1. Nuestra prevalidación YAML/JSON es estructural; no equivale a validación CLI o resolver. Registry se presenta como JSON para manipulación por scripts, **la ruta y gramática pueden necesitar ajuste al ejecutarse `vigilio-prompt --help`**. No copiar reglas que no correspondan al schema. El source `prompt-builder` ZIP no contiene `dist/` compilado. Requiere instalar dependencias y compilar en ambiente Node24; red/registry podrían estar indisponibles. `openspec` es repositorio de especificaciones y cambios, no reemplaza document owner ni prueba real. Validar con CLI oficial antes de producción.
