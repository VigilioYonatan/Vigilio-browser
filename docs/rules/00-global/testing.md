# Estrategia de pruebas sin desperdiciar memoria
Unitarios C++ core + SQLite fake as needed: por cada PR, paralelizables. Qt components (QTest) widgets/foco/señales: cada PR. Integración SQLite real y HTTP fixture local / WebEngine selectivo: cada cambio correspondiente. Contract tests adapters, backup versioning/MCP permission bridge. E2E FULL_BROWSER solo 1 instancia por runner, 1 worker, locks CTest (`RESOURCE_LOCK`), ejecutar smoke en PR seleccionados y suite amplia nightly/release. No sleeps fijos; esperar señales/eventos y estados con timeout. Fixtures locales deterministas, perfil efímero, cierre de render/subprocesos y cleanup. E2E críticos: cold start/navigate/tab restore, window split, download, Shields site override, local backup/export/import/delete, Senior keyboard, extensions compatible, MCP authorization/revocation, installer/uninstaller on native runners. No reemplazar E2E con mocks de WebEngine y llamarlo E2E.

Sanitizers ASan+UBSan separadamente de TSan. Fuzz JSON/YAML/CSV/backup/URL/SVG parsing; Unicode, malicious paths, huge input. Accessibility automated + human screens; benchmark total multiproceso RAM/CPU/startup/tab switching/1-5-10-20 tabs and memory pressure against pinned baseline; no artificial targets or % ahorro no medido. Matriz Win10/11 x64 Linux distro x64 macOS Intel arm64 condicionada a runners. Evidence statuses PASS/FAIL/BLOCKED/NOT_EXECUTED; artifacts logs redacted. Gates publish require build Qt/WebEngine native+QA manual, functional critical E2E, security boundaries, backup roundtrip, documents/asssets validation.
