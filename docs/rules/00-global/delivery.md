# Entrega multiplataforma
Target Windows 10/11 x64, Linux x64, macOS Intel/arm64, supeditado a matriz real del Qt elegido y pruebas de hardware. Windows Inno Setup/MSIX a decidir después de prototipo; exe instalador con bienvenida → ubicación → opciones → importación → progreso → fin; opciones no cambian browser por defecto sin consentimiento. Linux deb/AppImage con integración XDG; macOS .app/.dmg, entitlements, notarización y firma cuando recursos estén listos. En uninstall: opción conservadora por defecto conserva perfil; exportar por ruta seleccionada; eliminar perfil requiere acto afirmativo separado, contraseñas jamás en claro. Update: manual `Acerca de Vigilio → Buscar actualizaciones`, conexión de usuario explícita, firma/hash y downgrade prevention; no servicio de update residente. Proveedor de firma, licencia exacta y publicación pendientes; no publicar binarios con marca verified sin evidencia. `generated/` siempre gitignored; source headers sin referencias a toolchain generativo.
