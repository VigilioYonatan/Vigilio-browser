# Dirección UX/UI Senior — contrato canónico
**Marca**: globo/orbita azul violeta, sin glow excesivo. **Paleta**: Light bg #F7F9FC surface #FFFFFF text #172033 border #DCE3ED, Dark bg #111827 surface #1B2535 text #EEF2FF, acento #2563EB. **Tipografía**: Inter si licencia redistribuible verificada; Segoe UI/SF Pro/Noto Sans como fallback. **Iconos**: SVG 16-20px stroke ~1.8, nunca emoji ni icon font decorativa. **Espaciado**: 4px grid, 8/12px radius, motion 120-180ms, reduced motion. Desktop normal 14px base / Senior 18px base, target Senior ≥44-48px. La página nueva puede mostrar wallpaper; páginas web no reciben un fondo de marketing forzado.

**App chrome**: 38px top tab strip; 42px nav strip; sidebar colapsable 224px amplia / 64px compacta; menú del sitio junto a URL; escudo Shields; extensiones; menú final. Modificar por mediciones, no fijar píxeles que rompan DPI escalado. Con panel estrecho, sidebar minimiza; central browser retiene espacio y split panes pasan a tab stack si insuficiente. Barra de progreso solo cuando carga; URL bar muestra búsqueda/URL y sugerencias por teclado. Tooltip accesible para icon buttons.

**Senior Mode**: se ofrece en onboarding y se alterna Ajustes→Apariencia y accesibilidad y Ctrl+K. Cambiar sin pérdida de sesión ni reinicio cuando posible; preferencias por perfil local. Aumentar fuente, objetivos de clic, separación, contraste, reducción movimiento y etiquetas explícitas; simplificar capas de navegación y mandar secundarios a Más; NO esconder privacidad, salir de Senior ni permisos críticos. Lectura en voz alta a demanda; usar mecanismos del SO o motor opt-in. Foco visible y contrast ratio WCAG 2.2 AA donde aplicable; probar teclado y Narrator/VoiceOver/Orca en dispositivos reales.

**Screen contracts**: cada screen fija entry, owner, title, navigation, empty/loading/success/error/offline/stale states, keyboard, screen reader names, cancel/retry, resizing and test IDs. Dialog actions default safe, destructive explicit and undo when possible. Confirmations no dark-pattern (never preselect deleting profile). Comportamiento de onboarding, browser, context menu, Shields popover, Settings, Readers, Tools, MCP, Backup y Installer en docs/rules/05-reference/screen-inventory.md.
