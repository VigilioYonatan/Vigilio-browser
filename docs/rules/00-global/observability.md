# Observabilidad estrictamente local
Logger QLoggingCategory, error codes, trace-id por operación, rotación de logs y eliminación por el usuario. No URLs completas, queries, cuerpo de páginas, cookies, passwords, clipboard ni nombres de archivos sensibles por defecto. Logs persistentes opcionales; nivel mínimo por defecto. Métricas locales: UI latency p95, crashes, startup, tab lifecycle, adblock counters, CPU RAM de árbol multiproceso, extension process resources where measurable, MCP approved/denied counts; no exportadores remotos. Inspector Diagnostics comienza a muestrear bajo demanda, intervalos ajustables, límites CPU/RAM propios; cerrar panel detiene muestreo. Crash dumps con ruta controlada/opt-in y contenido sensible avisado. Cada métrica tiene owner/semántica, fixture y pruebas; alarma solo dentro de interfaz, no push al servidor. Falta establecer SLO medidos: no inventar thresholds.
