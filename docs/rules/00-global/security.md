# Seguridad y privacidad — límites
No account/cloud/sync/telemetry. QWebEngine sandbox always enabled; site origin separation; no exposing arbitrary file:// or QWebChannel to remote sites; CSP for local viewers; validate URL schemes, `javascript:`/`data:` and paths based on explicit policy. Passwords stored using OS keychain or equivalent encrypted provider after design review; never plain text SQLite/backup. Private profile is ephemeral, excluded from history/backups/agent enumeration unless explicitly safe and permitted. Adblock rule engine on worker, request interceptor fast and nonblocking; no remote debug port by default. Extensions MV3 permission review and optional load. MCP: authenticated local transport, per-client grants, least privilege, origin restrictions, prompt injection defense, no automatic cookies/password retrieval, confirmation on sensitive operations, expiry/revocation, local redacted audit. No arbitrary filesystem write for agents. Export via atomic writes, encrypted backups when they carry secret data; ZIP path traversal/zip bombs checked on import. Deletion requires separate explicit choice and confirmation, non-destructive option default. Threat model includes malicious site, extension, local agent, untrusted document, network attacker and compromised package. Test boundaries negative cases before release.
