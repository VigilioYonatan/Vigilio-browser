# Visores — bounded context
**Estado**: TARGET salvo funcionalidades explícitamente existentes en starter. **Owner canónico**: `docs/rules/01-modules/readers`. **Propósito**: MD, Mermaid, JSON, CSV, XML, PDF, EPUB, JSONL/YAML/TOML/INI/LOG/TXT/DIFF/HAR/HTTP/ICS/SVG. **Actores**: usuario local, Modo Senior/Normal/Experto, y agente MCP solo cuando el módulo lo permita. **Responsabilidades propias**: lazy viewers. **No posee**: cloud, login o sincronización Vigilio, telemetría remota ni permiso global para acceder a datos de otros módulos. **Contrato público**: interfaz C++ tipada entre capa de dominio y Qt UI, sin lógica del negocio incrustada en widgets. **Dependencias**: constitution.md, security.md, testing.md y contrato de UI común. **Integración**: publicar comandos a CommandRegistry cuando aplique, persistir solo con repositorios locales autorizados.

**Funciones objetivo**: MD, Mermaid, JSON, CSV, XML, PDF, EPUB, JSONL/YAML/TOML/INI/LOG/TXT/DIFF/HAR/HTTP/ICS/SVG. **Criterio de aceptación**: Isolate untrusted files; budget large datasets. **Fuera de scope inicial**: cualquier dependencia no implementada o no validada debe quedar GAP y con tests NOT_EXECUTED.
