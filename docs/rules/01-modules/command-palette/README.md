# Comandos — bounded context
**Estado**: TARGET salvo funcionalidades explícitamente existentes en starter. **Owner canónico**: `docs/rules/01-modules/command-palette`. **Propósito**: Ctrl+K, commands search tabs/history/bookmarks, hint navigation. **Actores**: usuario local, Modo Senior/Normal/Experto, y agente MCP solo cuando el módulo lo permita. **Responsabilidades propias**: CommandRegistry. **No posee**: cloud, login o sincronización Vigilio, telemetría remota ni permiso global para acceder a datos de otros módulos. **Contrato público**: interfaz C++ tipada entre capa de dominio y Qt UI, sin lógica del negocio incrustada en widgets. **Dependencias**: constitution.md, security.md, testing.md y contrato de UI común. **Integración**: publicar comandos a CommandRegistry cuando aplique, persistir solo con repositorios locales autorizados.

**Funciones objetivo**: Ctrl+K, commands search tabs/history/bookmarks, hint navigation. **Criterio de aceptación**: No hidden shortcut-only actions. **Fuera de scope inicial**: cualquier dependencia no implementada o no validada debe quedar GAP y con tests NOT_EXECUTED.
