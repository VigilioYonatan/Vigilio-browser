# Operación / recuperación — Seguridad y permisos
**Dependencias**: PermissionManager. **Modo degradado**: conservar navegación fundamental cuando la capacidad opcional falla y desactivar solo ese módulo con explicación visible. **Diagnóstico**: códigos de error `VIG-SECURITY-*`; contador local de fallos con usuario autorizado, sin datos de páginas. **Límites de capacidad**: budget de memoria por subcomponente configurable en bench, cancelación al cerrar la UI, backpressure en importaciones y tareas recurrentes. **Alertas**: local; usuarios podrán consultar y borrar registros. **Runbook**: reproducir, preservar copia antes de tocar datos, desactivar capacidad afectada, validar permisos, corregir root cause, tests específicos, rollback desde backup verificado. **SLO**: definir tras medición, nunca inventado. **Owner**: ingeniero de módulo; **security incident**: aislar capacidad, revocar permisos MCP si aplica; nunca cargar dump sensible a terceros automáticamente.
