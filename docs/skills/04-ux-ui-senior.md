# UX/UI Senior

## Estilo objetivo
- Interfaz moderna, sobria y profesional.
- Sin brillos exagerados ni look artificial.
- Azul oscuro como base, superficies limpias y contraste controlado.
- Iconos SVG consistentes; sin emojis.

## Componentes
- Barra de direcciones clara.
- Sidebar consistente.
- Tarjetas con jerarquía visual.
- Menús con estados hover, active, disabled y focus.
- Temas claros/oscuro/midnight/forest/sunset con tokens compartidos.

## Reglas
- Máximo reuso de componentes.
- Jerarquía visual evidente.
- Acciones primarias visibles.
- Mensajes de error comprensibles.
- Nunca sacrificar claridad por decoración.


## Lenguaje público de producto
Consulte `docs/UX-COPY-PUBLICO.md`: nunca mostrar «Senior Mode», «Modo Senior», prompts o terminología interna en la UI pública. Usar «Interfaz más fácil de usar». La referencia oficial del logo del instalador es `resultado/06-logo-instalador-oficial.png`.
