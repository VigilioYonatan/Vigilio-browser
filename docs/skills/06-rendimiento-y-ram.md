# Rendimiento y RAM

- Cargar herramientas pesadas bajo demanda.
- Reducir trabajo en segundo plano.
- Suspender o descartar pestañas inactivas cuando sea seguro.
- Medir RAM y CPU antes de afirmar mejoras.
- Los E2E del navegador no deben correr en paralelo si degradan la máquina.
- No arrancar MCP o utilidades opcionales si están desactivadas.
- Evitar fugas de memoria y objetos huérfanos.
