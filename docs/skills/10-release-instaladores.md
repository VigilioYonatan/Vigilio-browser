# Release, instaladores y desinstalación

## Instalador
- Flujo claro: bienvenida, ubicación, componentes, preferencias, instalación y finalización.
- No forzar login ni cloud.
- Permitir accesos directos, importación y configuración inicial.

## Desinstalador
- Ofrecer exportar configuración.
- Permitir conservar datos o borrarlos.
- Explicar acciones destructivas claramente.

## Release
- Checklist de firma, pruebas críticas, notas de versión y rollback.
- Verificar assets empaquetados y rutas correctas.
- Confirmar consistencia visual con `/resultado/`.
