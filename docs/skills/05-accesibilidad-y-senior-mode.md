# Accesibilidad y Senior Mode

## Accesibilidad base
- Navegación por teclado completa.
- Foco visible.
- Contraste adecuado.
- Etiquetas entendibles para lector de pantalla.
- Escalado de texto y layout robusto.

## Senior Mode
- Controles más grandes y legibles.
- Espaciado mayor.
- Texto ampliado.
- Tareas frecuentes primero.
- Vista previa dentro de ajustes.
- No ocultar permisos o acciones importantes.

## Criterios
- Todo cambio de UI debe decir cómo impacta a Senior Mode.
- Si no aplica, debe documentarlo explícitamente.


## Lenguaje público de producto
Consulte `docs/UX-COPY-PUBLICO.md`: nunca mostrar «Senior Mode», «Modo Senior», prompts o terminología interna en la UI pública. Usar «Interfaz más fácil de usar». La referencia oficial del logo del instalador es `resultado/06-logo-instalador-oficial.png`.
