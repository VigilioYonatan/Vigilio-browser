# Seguridad y privacidad

- Vigilio no tendrá cuenta, cloud ni sincronización propia.
- Todo dato del navegador es local salvo que el usuario interactúe con servicios web externos.
- Validar entradas, rutas, archivos importados y backups.
- El AdBlock/Shields debe ser seguro y reversible por sitio.
- MCP es opcional y con permisos explícitos.
- Nunca registrar datos sensibles de forma innecesaria.
- Acciones destructivas requieren confirmación y recuperación cuando aplique.
