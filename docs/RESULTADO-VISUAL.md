# Resultado visual objetivo

La carpeta `/resultado/` contiene el objetivo visual consolidado de Vigilio Browser.

## Qué debe reflejar el producto final
- **Home**: sidebar, búsqueda, accesos rápidos, espacios de trabajo y tarjetas de privacidad/rendimiento.
- **Tools**: visores integrados, utilidades rápidas y paneles de productividad.
- **Settings / Senior Mode**: tema, accesibilidad, toggles grandes, vista previa y organización clara.
- **Installer**: pasos, opciones, vista previa de marca y CTA claro.
- **Uninstaller**: exportar, conservar o eliminar datos con advertencias explícitas.

## Regla para micro-prompts
Todo cambio que afecte UI debe comparar su resultado con estas imágenes y explicar cualquier desviación necesaria.
