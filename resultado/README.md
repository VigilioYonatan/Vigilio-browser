# Resultado visual de referencia — Vigilio Browser

Esta carpeta contiene la **visión visual objetivo** del producto.
Todos los micro-prompts que afecten interfaz, experiencia de usuario, assets, branding, temas, accesibilidad, instalador o desinstalador deben revisar estas imágenes antes de proponer o implementar cambios.

## Archivos incluidos

1. **01-vigilio-home.png** — Pantalla principal del navegador con sidebar, buscador, espacios y tarjetas de privacidad/rendimiento.
2. **02-vigilio-tools-productivity.png** — Centro de herramientas con visor Markdown, explorador JSON y utilidades rápidas.
3. **03-vigilio-settings-senior-mode.png** — Ajustes y accesibilidad con Modo Senior, toggles grandes y vista previa.
4. **04-vigilio-installer.png** — Flujo del instalador con pasos, ubicación, componentes y preferencias.
5. **05-vigilio-uninstaller.png** — Flujo del desinstalador con exportación, conservación o borrado de datos.

## Cómo usar esta carpeta

- **PROPOSE**: debe citar las imágenes relevantes y explicar cómo el cambio preserva o acerca el resultado final.
- **APPLY**: solo debe modificar el microcambio actual, sin romper el diseño objetivo ni introducir estilos ajenos.
- **REVIEW**: debe comparar el resultado con estas referencias y documentar desviaciones visuales, de accesibilidad o consistencia.

## Dirección artística resumida

- Estética moderna y profesional, **sin apariencia genérica de IA**.
- Interfaz sobria, tonos azul oscuro y superficies controladas.
- Tipografía Inter + fallback del sistema.
- Iconografía SVG consistente, sin emojis.
- Modo Senior con tamaños mayores, contraste y controles amplios.
- Privacidad local: sin cloud de Vigilio, sin login, sin sincronización propia.

## Nota

Estas imágenes son **referencia de objetivo visual**, no prueba de funcionalidad implementada.
